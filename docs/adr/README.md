# Architecture Decision Records

Architecture Decision Records (ADRs) capture decisions that are expensive to
reverse or affect multiple packages. Create one for changes to deployment
boundaries, graph contracts, parser technology, storage, AI providers, or
security posture.

Copy [`0000-template.md`](0000-template.md), assign the next sequential number,
and use a short, descriptive filename such as `0001-local-agent-boundary.md`.
ADRs are immutable after acceptance; supersede a decision with a new ADR rather
than rewriting history.
